# 电力现货交易（储能套利）领域规则

来源：2026-07 某省级现货市场储能交易 PoC（已脱敏）。每条规则标注了泛化程度——
"行业通用"可直接沿用，"需客户校准"必须在新客户的步骤 1 重新确认参数。

## 商业模式与市场结构

- **储能核心商业模式**：现货市场"低充高放"套利——低价时段充电、高价时段放电，
  充电窗口必须先于放电窗口（时序硬约束）。行业通用。
- **现货出清粒度**：15 分钟一个交易点，每交易日 96 点（QH 出清）。省级现货市场
  通用；具体省份的出清规则细节需客户校准。
- **充放电窗口**：PoC 常用各 4 小时窗口（16 × 15min 点）做优化演示；实际窗口由
  电池倍率（C-rate）与容量决定——需客户校准，方案书示例参数（如 100MW/200MWh）
  不可直接当真实参数用。

## 预测与数据质量

- **预测质量判定标准**：模型 MAE/RMSE 必须优于"日同期朴素基线"（naive
  same-period baseline），预测区间覆盖率达标（如 80% 区间），且满足最小样本量
  门槛——三条同时成立才算预测有效。这个判定框架行业通用，阈值需客户校准。
- **数据卫生红线**：非完整交易日直接剔除，不做价格插补——缺失数据不得静默伪造
  为模型输入。行业通用（监管与审计语境下尤其重要）。

## 安全与合规边界

- **PoC 输出硬边界**：不得生成申报曲线、交易提交指令或储能控制工件——用输出
  路径断言（禁止 token 列表）在代码层强制，不靠自觉。行业通用，属 PoC 安全
  红线。
- **风控规则形态**：SOC 上下限（如 ∈ [10%, 90%]）、日充放次数上限、辅助服务
  预留容量等。规则形态行业通用；具体数值属客户生产范围，PoC 仅做规则拦截演示，
  不代客户定值。
- **真实结算/合同数据**：绝不进入 PoC 处理流程、不上传云端、不出现在演示中。
  需要真实生产数据时走 GenAIIC 共创审批。

## 区域技术约束

- **中国区（BJS/ZHY）无 Bedrock**：LLM 能力采用区域内现成推理端点（如
  SageMaker JumpStart 开源模型或客户认可的 API），不为 PoC 自建 GPU 推理。
  中国区通用。
- **中国区定价**：Price List API 在 cn 分区可用（`pricing.cn-northwest-1`
  端点，CNY 计价，已实测）——费用测算直接取实时报价，官网定价页作交叉核对。

## 步骤 1 校准清单（新客户必问）

- 交易标的与出清规则的确切定义（不同省份市场规则差异大）
- 电池真实参数：容量、倍率、效率、循环约束
- 预测质量阈值是否设硬性验收线
- 客户验收人与演示排期
- LLM 端点选型与合规边界
