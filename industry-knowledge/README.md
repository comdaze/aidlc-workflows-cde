# 行业知识包（Industry Knowledge Packs）

跨项目复用的行业领域知识，来源于已完成的客户 PoC 交付，经脱敏审查后沉淀。
每个行业一个目录，内容为领域规则、架构模式与踩坑记录——不含任何客户名称、
真实数据或未经批准的材料。

## 使用方式

新项目启动（八步流程的步骤 1 之前），把目标行业的目录拷进项目的团队知识层：

```bash
cp -r <repo>/industry-knowledge/<industry>/ <project>/aidlc/spaces/default/knowledge/aidlc-shared/<industry>/
```

拷入后所有 agent 可读（L4 团队知识层），步骤 1 的领域知识捕获以它为起点做
客户校准——继承的是"上一个同行业 PoC 学到的"，校准的是"这个客户不一样的"。

## 贡献方式

PoC 完成后，从该项目的领域知识捕获工件（L5）和 ADR 中提炼可泛化内容：

1. 脱敏：删除客户名、人名、真实数据文件引用、结算/合同信息
2. 泛化：客户特定参数改为"待客户校准"的占位描述
3. 提交 PR 到本目录，注明来源 PoC 的时间与行业（不注明客户）

红线：客户机密永不入库；拿不准是否敏感的内容，走 GenAIIC 审查后再入。
